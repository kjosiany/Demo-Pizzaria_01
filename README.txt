FORNO DA VILA — SITE DEMONSTRATIVO

Site estático de apresentação para uma pizzaria de bairro.

O projeto foi refeito usando as imagens fornecidas, com foco em uma aparência simples,
comercial e natural, sem carrinho, checkout, login ou sistema de pedidos.

ARQUIVOS
- index.html
- style.css
- script.js
- img/ — imagens fornecidas para o projeto

CONTATO DEMONSTRATIVO
WhatsApp: 3499152341

IMPORTANTE
Este é um projeto demonstrativo. Fotos, endereço, horários, produtos, preços e demais
informações exibidas são ilustrativos e devem ser substituídos pelos dados reais do cliente.

Para personalizar:
1. Troque o nome da pizzaria.
2. Atualize endereço, horários e textos.
3. Substitua os preços e sabores.
4. Mantenha o WhatsApp 3499152341 conforme a regra deste projeto.
5. Troque as imagens da pasta img quando o cliente fornecer fotos próprias.

PEDIDO PELO SITE
Os botões de pedido são interativos: ao clicar em uma pizza ou bebida,
o site abre o WhatsApp com uma mensagem inicial já preenchida.
Não existe carrinho, checkout ou pagamento dentro do site.
